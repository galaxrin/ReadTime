# ReadTime 全局无边框 UI 设计

## 目标

五套主题的全部界面移除容器、控件和分隔线边框，交互控件改用背景与文字高亮表达悬停、焦点和选中状态。

## 规则

- 阅读区、页眉、空状态、控制条、目录、设置面板、主题卡、提示块、输入框、下拉框、按钮和滑块圆点不绘制边框或焦点外框。
- 普通状态通过现有主题背景层级区分。
- `hover`、`focus-visible` 和 `active` 使用当前主题文字色或强调色混合出的半透明背景。
- 选中状态同时增强背景和文字颜色。
- 保留现有圆角、面板投影与毛玻璃效果。
- 保留 SVG 图标内部线条；它们属于图标内容，不属于界面边框。
- 禁用状态继续使用透明度表达。

## 实现范围

仅修改：

- `src/renderer/components/ReadingView.css`
- `src/renderer/components/ControlBar.css`
- `src/renderer/components/Settings.css`

不新增组件、主题变量、状态或依赖。

## 验收

- 五套主题中不存在可见的容器边框、控件边框、分隔线或焦点外框。
- 鼠标悬停、键盘聚焦和选中状态均有清晰的背景高亮反馈。
- 设置面板、控制条和目录仍可通过背景、阴影与圆角识别。
- SVG 功能图标保持完整。
- 现有测试和生产构建通过。
