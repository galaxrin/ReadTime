# ReadTime 菜单栏启动设计

## 目标

将 ReadTime 调整为 macOS 菜单栏应用：启动后不出现在 Dock、不自动显示阅读窗口，通过顶部栏图标控制窗口。

## 启动行为

- macOS 启动后调用 `app.dock.hide()`。
- 创建原生 Electron `Tray` 图标。
- 创建阅读窗口但保持隐藏，确保全局老板键和顶部栏操作可立即使用。
- 其他平台保留现有启动行为。

## 顶部栏交互

- 左键点击图标：切换阅读窗口显示与隐藏。
- 右键菜单：
  - `显示阅读窗口` 或 `隐藏阅读窗口`，文案随窗口状态变化。
  - `退出 ReadTime`，真正结束应用。
- 窗口显示时恢复上次位置并获得焦点。

## 窗口与退出

- `Cmd + Shift + H` 继续切换窗口显示与隐藏。
- 普通窗口关闭操作只隐藏窗口，不销毁应用。
- 只有顶部栏菜单的退出操作或系统退出事件终止应用。

## 实现约束

- 使用 Electron 自带的 `Tray`、`Menu` 和 `nativeImage`。
- 不增加依赖。
- 菜单栏图标使用项目内的 macOS 模板图资源；若没有现成资源，则新增一张最小单色模板图。
- 不改变阅读、主题、文件解析或进度逻辑。

## 验收

- 启动后 Dock 中无 ReadTime 图标。
- 启动后阅读窗口默认隐藏，macOS 顶部栏显示 ReadTime 图标。
- 左键、右键菜单和老板键均能正确显示或隐藏窗口。
- 隐藏窗口后应用继续运行。
- 从右键菜单退出后进程结束，顶部栏图标消失。
