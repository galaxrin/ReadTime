# ReadTime 系统听书功能设计

## 目标

为现有 TXT/EPUB 阅读器增加离线系统语音朗读。用户从当前阅读位置开始听书，正文同步高亮并跟随滚动，当前章节结束后自动朗读下一章。

## 第一版范围

- 使用 Electron 渲染进程提供的 Web Speech API（`speechSynthesis`）。
- 使用 macOS 默认中文系统音色，不提供音色选择。
- 控制栏提供独立的听书播放/暂停按钮。
- 设置提供 0.75×、1×、1.25×、1.5×、2× 语速，默认 1×并持久化。
- 从当前视口内第一条可见句子开始朗读。
- 当前句高亮，并在朗读推进时平滑滚入可视区域。
- 当前章节朗读完毕后自动进入并朗读下一章；全书结束后停止。
- 听书与自动滚动互斥。

不包含 AI 音色、云端语音、音频文件生成、后台播放、系统媒体键、音色选择和跨设备同步。

## 实现设计

### 文本与定位

正文按中文和英文句末标点及换行拆分为保留原文的句子片段。`ReadingView` 将片段渲染为带索引的行内元素，不修改已有章节内容。

开始朗读时，读取正文容器与句子元素的位置，选择第一个与可视区域相交的句子；若没有相交项，则选择距离视口顶部最近的句子。章节自动切换后从第一句开始。

现有 `currentLine` 阅读进度继续负责保存滚动位置。听书跟随滚动会触发现有进度更新，不新增第二套书籍进度格式。

### 朗读状态

新增一个渲染层听书 hook，持有：

- 播放或暂停状态
- 当前章节与句子索引
- 当前句对应的 `SpeechSynthesisUtterance`
- 语速
- 可展示的错误

每次只把一句交给 `speechSynthesis`。句子结束后推进索引；章节结束时调用现有 `nextChapter()`，等待新章节渲染后继续。这样避免超长章节的单次 utterance 限制，也能直接以句子索引驱动高亮。

暂停调用原生 `speechSynthesis.pause()`，恢复调用 `resume()`。切换书籍、手动切换章节或组件卸载时调用 `cancel()` 并清理当前状态。打开设置不停止朗读。语速改变后取消当前 utterance，并从当前句按新语速继续。

### 界面行为

控制栏在现有自动滚动按钮旁增加听书按钮：

- 未播放：播放图标，标签“开始听书”
- 播放中：暂停图标，标签“暂停听书”
- 无书籍或无正文时禁用

设置页增加“听书语速”，沿用现有速度选项样式。当前朗读句使用主题强调色的低透明背景和圆角，不添加固定文字颜色，保证所有现有主题可读。

开始听书时停止自动滚动；开始自动滚动时停止听书。朗读推进仅在当前句离开可视区域时滚动，避免页面每句抖动。

### 错误与边界

- `speechSynthesis` 不可用或系统无可用语音时停止朗读并显示简短错误，阅读功能保持可用。
- 空章节直接进入下一章。
- 手动切书、目录跳章、上一章或下一章操作停止听书，不自动在新位置续播。
- 朗读事件使用会话标识忽略被取消 utterance 的迟到回调，避免重复推进。

## 验证

最小自动化检查覆盖：

- 中英文标点、换行和空文本的句子拆分。
- 从可见句子索引开始。
- 句子结束推进、空章节跳过、末章结束停止。
- 听书与自动滚动互斥。
- 语速保存和恢复。

手动验证覆盖：

- TXT 与 EPUB 从当前滚动位置开始。
- 播放、暂停、恢复、调速。
- 高亮与自动跟随。
- 自动跨章、全书结束。
- 手动切书/切章停止。
- 所有阅读主题下高亮可读。
