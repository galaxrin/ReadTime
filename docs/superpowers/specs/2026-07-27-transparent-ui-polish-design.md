# ReadTime 透明模式 UI 细节修正

## 目标

- 透明主题下移除底部控制条和设置面板的可见边框，消除半透明描边的锯齿感。
- 设置面板圆角统一为主悬浮窗使用的 `18px`。
- 所有主题的阅读文字、章节标题和页眉不再绘制文字阴影。

## 实现

- 在透明主题选择器中覆盖 `.control-bar` 和 `.settings-panel` 的边框与模拟内边框。
- 将 `.settings-panel` 的 `border-radius` 从 `22px` 调整为 `18px`。
- 将主题配置中的 `textShadow` 统一设为 `none`，继续沿用现有 CSS 变量链路。

不新增组件、状态、主题字段或依赖。

## 验收

- 透明白字、透明黑字主题下，底部控制条和设置面板无可见描边。
- 控制条、设置面板仍通过现有半透明背景和阴影保持可辨识。
- 设置面板与主悬浮窗圆角均为 `18px`。
- 正文、章节标题和页眉均无黑色描边或文字阴影。
- 现有测试与构建通过。
