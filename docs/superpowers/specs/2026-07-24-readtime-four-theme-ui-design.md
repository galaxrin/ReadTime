# ReadTime 四主题 UI 设计

## 目标

在不改变阅读、文件解析和进度逻辑的前提下，重做 ReadTime 的视觉层级，并提供四套可即时切换、重启后保留的阅读主题。

## 主题

1. **纸张阅读**：暖白纸张背景、深色正文、柔和分隔线。
2. **静谧深色**：深灰渐变背景、暖白正文、低对比控件。
3. **macOS 玻璃**：半透明浅色面板、背景模糊、轻边框。
4. **纯透明白字**：阅读区域完全无底色，白字配深色柔和阴影，桌面内容直接透出。

四套主题共用一套组件结构，仅通过 CSS 变量改变背景、文字、阴影、边框和控件表面。

## 界面结构

- 阅读区：书名与章节进度置于顶部，章节标题和正文形成明确的排版层级。
- 控制条：悬停时在底部浮现，包含上一章、进度、下一章和设置入口。
- 设置面板：显示四个主题预览卡，并保留字号、行距和文字透明度滑块。
- 空状态：使用与当前主题一致的背景和拖拽提示。

透明主题下，阅读区不绘制任何背景；控制条和设置面板仍使用低透明毛玻璃表面，保证操作可识别。

## 状态与持久化

沿用现有 `ThemeManager` 和 `SettingsContext`：

- 主题对象增加界面所需的 CSS 变量。
- `ThemeManager` 将当前主题、字号、行距和文字透明度写入 `localStorage`。
- 启动时读取保存值；数据缺失或损坏时回退到默认主题。
- 切换主题不影响当前书籍、章节和阅读进度。

## 范围

修改现有 React 组件和 CSS，不增加 UI 库、不新增状态框架、不改变文件解析、老板键或阅读进度协议。

## 验收

- 四个主题均可从设置中切换。
- 切换后阅读区、控制条、设置面板和空状态保持统一视觉。
- 纯透明白字主题的阅读区无底色。
- 主题、字号、行距和文字透明度在重启后恢复。
- 老板键、拖拽导入、章节切换和现有测试不受影响。
- 构建成功，并在实际 Electron 窗口中检查四套主题。
