# 透明主题控制面板与胶囊开关设计

## 目标

- 透明主题继续保持阅读背景透明。
- 透明主题的悬浮控制条和设置面板统一使用不透明深灰 `#181b1f`。
- “鼠标移出自动隐藏”使用带 `ON` / `OFF` 文案的胶囊开关。

## 实现

- 仅调整透明主题的表面颜色变量，不影响其他 11 套主题。
- 控制条和设置面板继续复用现有主题变量，不增加专属组件。
- 保留原生 `checkbox`，通过 CSS 绘制胶囊轨道、状态文字和滑块。
- 开启状态使用当前主题强调色，关闭状态使用中性灰。
- 保留鼠标、键盘和屏幕阅读器可操作性。

## 验收

- 透明主题的阅读区域无背景。
- 透明主题的控制条和设置面板均为不透明 `#181b1f`。
- 自动隐藏开关关闭时显示 `OFF`，开启时显示 `ON`。
- 点击文字或开关均可切换，键盘操作不受影响。
- 其他主题、主题菜单和自动隐藏逻辑不变。
- 测试与生产构建通过。
